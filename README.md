# IronSteerer
Mimicking an Iron bar to steer the beamline

## Description
This project is meant as a larger Kassiopeia project modelling the beamline trajectories for our electron accelerator. This specficially is to calibrate the parameters needed to produce a 100 Gauss azimuthal magnetic field after the electrodes have accelerated the electrons. 

## Requirements
One would need to have Kassiopeia installed and running within their personal machine to be able to run this code. Instructions for installation and setup are provided by the Kassiopeia developers themselves here: 
https://katrin-experiment.github.io/Kassiopeia/setup_manual.html

## Elements
The xml file included is the file that is used to setup and run the Kassiopeia simulation. The included jupyter notebook is for analysis of the output ROOT file.
